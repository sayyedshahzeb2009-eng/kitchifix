# KitchiFix — Shopify 3D Theme

Premium Shopify Online Store 2.0 theme for KitchiFix.

## Included
- 3D GLB/GLTF hero via model-viewer
- Interactive product showcase
- AJAX quick-add and cart drawer
- Dynamic Shopify products and collections
- Responsive mobile design
- Theme Editor settings and section presets
- Product, collection, cart and page templates
- Reviews, FAQ, trust badges, newsletter and category sections

## Shopify
Connect this repository to Shopify from **Online Store → Themes → Add theme → Connect from GitHub**. Use the `main` branch.

After connecting, open the Shopify Theme Editor and configure your logo, colors, collections, copy, social links and 3D model URLs.

## 3D models
The Hero and Product Showcase accept public `.glb` or `.gltf` URLs. For production, use optimized models and a fast CDN.

## Before launch
Replace placeholder reviews, delivery/return language, policy pages and social links with your real store information.
